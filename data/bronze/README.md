# Bronze Layer - Raw Ingestion

This folder is the entry point for the pipeline. It is intended to hold the raw, untouched CSV files provided for the competition.

**Note on Large Files:**
The raw competition datasets have been removed from this directory to comply with submission size limits and data privacy. To run the pipeline, please place the following files in this folder:
- `transactions_history_final.csv`
- `outlet_master.csv`
- `outlet_coordinates.csv`
- `distributor_seasonality_details.csv`
- `holiday_list.csv`
