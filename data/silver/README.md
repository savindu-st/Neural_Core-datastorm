# Silver Layer - Cleaned Data

This folder contains the sanitized and validated datasets produced by the `src/data_pipeline/clean.py` script. 

**Note on Large Files:**
Due to competition submission size limits, the large `.parquet` and `.csv` files in this directory have been removed from the final ZIP/GitHub repository. These files can be perfectly reproduced by running the following command:

```bash
python -m src.data_pipeline.clean
```
