     compute time from 36 hours to under 3 minutes).

C. Distance-Decay Intelligence (src/spatial/distance_decay.py)

          insufficient; closer POIs needed stronger influence.
   - How: Developed a continuous exponential decay model.
   - AI Contribution: Devised a multi-scale exponential decay function:
       decay_score = sum( exp(-distance_m / decay_factor) )

     2000m for regional hospitals) to reflect human spatial behavior.

Prompt 1: "We are building a spatial intelligence pipeline for 20,000 retail 
outlets in Sri Lanka. The raw coordinates dataset contains some corrupted rows

- Outcome: AI generated a robust, vectorized logical mask:

  This formed the basis of our `clean_outlet_coordinates` repair system, saving
  hundreds of data points from deletion.

Prompt 2: "Simple fixed-radius counts of POIs like schools and fuel stations 
are not enough. We want closer POIs to have a stronger influence on sales than 
distant ones, following a smooth mathematical curve. How do we implement a 
scalable exponential distance-decay scoring system in Python that calculates 
vectorized distance-decay scores for multiple POI categories using SciPy KD-Trees?"
- Outcome: AI proposed using KD-Tree distance queries:
    distances, indices = tree.query(outlet_coords, k=max_k, distance_upper_bound=max_dist)
  Then applying `np.exp(-d / factor)` to the distance array, ignoring infs. This
  allowed massive performance gains and elegant mathematical modeling.

Prompt 3: "How can we systematically formulate a 'Market Saturation Index' 
for each retail outlet using its distances to nearby competitors? We need a 
single numeric score that ranges from 0 to 100 representing how crowded or 
isolated the outlet's local market is compared to average retail densities."
- Outcome: AI designed a density-ratio normalization scheme:
    MSI = (Competitor_Decay_Score / Median_Competitor_Decay_Score) * 50
  capped at 100, which became the core of the `catchment_density.py` logic.
